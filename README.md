# Open Stage Cue 🎭 🔊

**Open Stage Cue** is a low-latency, open-source sound playback system built for stage managers, sound operators, and community theatres. 

Designed to run smoothly on Android and iOS tablets, it replaces clunky laptops and proprietary software with a reliable, dual-mode interface: a linear cue stack for scripted scenes, and a live cart grid for looping background ambiances (rain, insects, fire).

- ⚡ **Zero-Latency Triggers:** Powered by low-level native audio engines.
- 📜 **Linear Cue Stack:** Spacebar/Tap "GO" workflow with customizable auto-fades.
- 🎛️ **Cart Wall:** Instant, one-touch buttons for background sound effects and loops.
- 📱 **Mobile & Tablet First:** Responsive touch UI built with React Native.
- 🔓 **Fully Open Source:** MIT Licensed.
